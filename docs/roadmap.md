# Roadmap and scope

## v0.1: inspectable foundation

- Installable CLI and newly authored synthetic workspace.
- Editable watchlist and verified-release planning.
- Knowledge context + portfolio policy arithmetic.
- Agent-host skill, structured proposal contract, staging, traces and explicit apply.
- Behavior tests and honest separation of fixture replay from live reasoning.

## Next integration milestone

- Validate one actual host/plugin combination end to end with a user-owned account.
- Normalize provider responses with explicit data gaps, classification dates and FX.
- Verify an official earnings-date source for a small user watchlist.
- Capture a manual live research run with original-source checks and staged changes.

## Subsequent work

- Reusable source-ingestion and knowledge-maintenance tools.
- Automated tests of tool failure/retry behavior in the host runtime.
- More complete valuation scenarios and user policy definitions.
- Optional scheduler/transport integrations, chosen from actual use needs.

No video, backtest or order-execution feature is planned for this first delivery.
No timeline or investment-quality improvement is implied by this list.
