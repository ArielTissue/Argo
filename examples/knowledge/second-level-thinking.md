# Second-level thinking

Ask what the market already expects, where the analysis differs, and why the evidence warrants that difference. Replace “the business will grow” with a testable disagreement about growth, margins, reinvestment or durability. Consider what happens if consensus is right and the analysis is wrong. Contrarian positioning alone is not an advantage. If the disagreement cannot be supported or does not compensate for uncertainty and costs, record that there is no demonstrated edge.

Related: [[price-and-value]] · [[bear-case]] · [[decision-quality]]

## Disagreement worksheet

1. Write a concrete consensus assumption and state how it was observed; if consensus is unavailable, label it an inference.
2. State one alternative assumption and the evidence supporting it.
3. Describe outcomes if either assumption is wrong, including opportunity cost.
4. Reject an unsupported contrarian story even when it sounds original.
