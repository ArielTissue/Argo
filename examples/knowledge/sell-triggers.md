# Designing reassessment and exit triggers

Before a decision, specify observable facts that would invalidate the thesis, the date by which a milestone should occur, and any separately chosen price protection. Avoid phrases such as “obvious deterioration” without a measurable condition. Distinguish temporary adversity from a broken mechanism. Explain what would make an exit judgment mistaken, too. A long-term investment and a short-term experiment require different review conditions; a loss should not silently change the position’s original purpose. These are analysis prompts, not automatic orders.
